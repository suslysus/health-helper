# HealthLog logo v1

Generated with the built-in image generation tool. The app's existing black and yellow palette informed the design. The H monogram's ascending crossbar suggests training progress.

## Generation prompt

Use case: logo-brand
Asset type: production app logo / square launcher icon for HealthLog, a personal adaptive strength-training coach and exercise, weight and meal log.
Primary request: Create one original, polished, minimal geometric H monogram. Two bold upright stems joined by a single ascending angular crossbar, subtly suggesting training progress and a logged activity pulse. The whole silhouette should read immediately as a strong H, with well balanced negative space and slightly softened corners. Confident, disciplined, contemporary fitness brand.
Style/medium: precise flat vector-like graphic rendered as a bitmap; very clean edges, minimal geometry.
Color palette: solid near-black #0A0A0A symbol on solid warm yellow #F5C84C background, matching the existing app palette.
Composition/framing: square canvas, yellow background fills every edge with NO rounded tile boundary. One centered black symbol occupies approximately 58 percent of canvas width and height; generous equal safe margins for Android icon masking. Front-facing 2D artwork only.
Constraints: one logo only; no presentation sheet, no device mockup, no perspective, no shadows, no gradients, no textures, no border, no watermark. No wordmark, no slogan, no tiny decorative elements. No medical cross, no heart, no dumbbell clip art. Highly legible at 32 pixels. Output a high resolution square image.
