# Health Helper

개인용 운동 계획 및 기록 앱입니다. 전신, 상·하체, PPL, 혼합형 중 목표와 선호에 맞는 방식을 선택합니다. 계획은 주당 횟수가 아니라 운동 순서의 반복 주기로 저장되므로 4회 순환이 주 경계를 넘어 이어질 수 있습니다. 등 운동을 하는 날에는 직전 등 운동과 다른 종목 구성을 고르는 규칙을 사용합니다.

## 현재 기능

- 첫 실행 시 목표, 경험, 선호와 주의사항 입력
- OpenAI API로 계획 초안과 다른 방식의 장단점 제안, 필요한 경우 짧은 추가 질문
- AI 연결 전에도 사용할 수 있는 기본안
- 프로필 → 운동 장소 관리 → 추가하기에서 장소 이름과 기구를 저장. 문장으로 설명하면 OpenAI가 입력칸에 이름과 기구를 정리하며, 저장 전 직접 확인할 수 있음
- 운동 준비에서 그날의 시간을 선택하고 저장된 장소를 고른 뒤, 그 장소의 기구에 맞게 종목 생성
- 오늘만, 앞으로 계속, 목표 변경의 세 가지 수정 범위
- 종목 직접 교체·추가·제외, 세트별 중량·반복수·RIR 및 휴식 타이머
- 운동 계획과 실제 완료 기록을 기기의 브라우저 저장소에 보관

식사·회복 탭은 이전 UI 예시 단계입니다. 운동 계획과 달리 현재 그 기록은 영구 저장하지 않습니다.

## 로컬 실행

Node.js 22 이상이 필요합니다.

```powershell
npm install
Copy-Item .env.example .env.local
```

`.env.local`에 본인의 `OPENAI_API_KEY`를 입력하고 `npm run dev`를 실행합니다. 키가 없으면 기본안과 수동 운동 수정은 사용할 수 있지만 AI 제안 버튼은 비활성화됩니다. `.env.local`은 Git에서 제외되며, 키를 채팅이나 GitHub에 올리지 않아야 합니다.

```powershell
npm run dev
npm test
npm run build
npm start
```

개인용 서버는 기본적으로 `127.0.0.1`에만 열립니다. OpenAI API 키는 서버 환경변수에서만 읽고, 앱 화면이나 번들에 포함하지 않습니다. 안드로이드 기기에서 네트워크 밖에서도 AI를 사용하려면 이후 인증을 갖춘 개인용 HTTPS 서버를 연결해야 합니다. 현재 저장소는 웹 프론트엔드와 로컬 API 서버까지 구현되어 있으며 APK 빌드는 Android Studio 설치 후 진행합니다.
