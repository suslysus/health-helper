# Health Helper

운동, 식사, 회복 기록을 한 화면 흐름으로 관리하는 모바일 우선 프론트엔드입니다.

## 주요 화면

- 달력을 첫 화면 최상단에 배치한 홈
- 중량, 반복수, RIR, 세트 휴식 타이머를 포함한 운동 기록
- 간단한 영양 요약과 식사 직접 입력
- 수면 및 컨디션 기록
- 신체 정보, 보유 기구, 프로그램, AI 연결 설정

검정, 흰색, 회색을 기본으로 사용하고 노란색만 강조색으로 사용합니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`로 생성합니다.
